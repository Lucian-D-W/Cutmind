# 本地字体资产

本地工作目录保留阿里巴巴普惠体 Light、Regular、Medium、Bold、Heavy 五个
TTF 原件。文件内版本字段均为 **Version 1.10**；作者已于 2026-10-26 确认其商用许可。

当前界面使用系统字体，不读取这些文件；安装配置也不把本目录打包为字体资源。
因此，不携带 TTF 的公开源码副本仍可安装依赖、构建和运行。

## 公开副本的范围

- 五个字体原件继续保存在作者本机和原有本地 Git 历史中。
- 本次准备的公开源码副本只保留这份说明，不包含五个 TTF。
- `GPL-3.0-only` 是本项目原创材料的许可，不是对第三方字体重新授权。
- 字体的商用使用与字体文件的转载分发是不同范围；目前材料未附与这些 v1.10
  文件对应的完整分发条款，所以不把其他版本的声明套用到这些文件上。

需要字体时请从[阿里巴巴字体官方入口](https://www.alibabafonts.com/)取得，
并遵循所下载版本随附的条款。这里不镜像第三方下载站的字体文件或授权声明。
